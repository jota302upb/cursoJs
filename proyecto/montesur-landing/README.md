# Montesur | Premium Landing Page

Una landing page de lujo diseñada para **Montesur**, enfocada en la agroindustria premium y el bienestar integral. La web utiliza una estética "Dark Luxury" con un color verde oliva profundo (#4B6323) como acento principal.

## 🚀 Características

- **Diseño Dark Luxury:** Fondo negro puro con elementos en gris ultra-oscuro y acentos verdes.
- **Glassmorphism:** Uso intensivo de efectos de desenfoque de fondo y transparencias en cards y navegación.
- **Interacción 3D:** Flip cards interactivas para los servicios, revelando detalles al pasar el cursor.
- **Sistema de Partículas:** Un fondo dinámico con partículas flotantes que añaden profundidad.
- **Animaciones de Scroll:** Revelado suave de secciones y contadores animados para las métricas de negocio.
- **Responsive Design:** Totalmente adaptada desde monitores XL hasta dispositivos móviles.

## 🎨 Sistema de Diseño

- **Color Principal:** `#4B6323` (Verde Oliva Profundo)
- **Tipografía:** 
  - Títulos: *Plus Jakarta Sans*
  - Cuerpo: *Inter*
- **Efectos:** Glow effects, 3D float, Glassmorphism, Pulse-glow.

## 📸 Imágenes Utilizadas

Debido a limitaciones temporales en la generación de imágenes por IA, se han utilizado imágenes de stock premium de **Unsplash** que capturan la esencia de la marca:
- **Hero:** Plantación de aguacates y naturaleza.
- **Servicios:** Agricultura de precisión, logística global, cuidado natural y comunidad.
- **Logo:** Sourced as a custom SVG created specifically for Montesur.

## 📁 Estructura del Proyecto

```
/
├── index.html      # Estructura y contenido
├── styles.css       # Estilos, animaciones y responsive
├── script.js        # Lógica de animaciones y partículas
└── images/
    └── logo.svg     # Logo corporativo Montesur
```

## 🛠️ Personalización

Para cambiar las imágenes, simplemente sustituye las URLs en el archivo `index.html` o descarga tus propias imágenes en la carpeta `images/` y actualiza las rutas.
